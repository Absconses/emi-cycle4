# EMI cycle 4

Plateforme d'éducation aux médias et à l'information pour le collège : livres interactifs H5P (5e, 4e, 3e) et Game Maps de fin d'année, à faire en autonomie.

- `index.html` : les modules par niveau et par domaine, avec la progression de l'élève (enregistrée dans son navigateur).
- `enseignant.html` : le tableau de classe, à partir des bilans que les élèves téléchargent.
- Détails dans `LISEZMOI.txt`.

Site statique servi par GitHub Pages. Lecteur : [h5p-standalone](https://github.com/tunapanda/h5p-standalone) 3.8.0.
