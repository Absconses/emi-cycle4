Le tableau du club

Dépose ici les bilans que les reporters ont téléchargés : le tableau de leur progression s’affiche aussitôt. Les fichiers sont lus dans ton navigateur ; rien n’est envoyé ni conservé en ligne.

 ✓ 85 %  terminé, avec le meilleur score ·  40 %  part du module faite · — pas commencé.
Le score est le total des points obtenus sur toutes les questions notées du module (QCM, glisser-déposer, écrits notés par mots-clés, badge) : une question pas encore faite compte 0. Pour un module terminé, c’est donc son taux de bonnes réponses ; pour un module en cours, il monte au fil des réponses. On garde le meilleur score obtenu.

Sceau. « ✓ intact » : le fichier n’a pas été retouché depuis que le site l’a produit, et il appartient bien à l’élève nommé (changer le nom casse le sceau). « ⚠ modifié » : quelqu’un a changé le fichier à la main. Le sceau arrête la retouche ordinaire, pas un élève qui fouillerait le code du site ou manipulerait son navigateur : c’est un indice de confiance, pas une note certifiée.
